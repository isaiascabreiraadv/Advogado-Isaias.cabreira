# Site do Escritório de Advocacia Dr. Isaías Cabreira

Site completo em HTML, CSS e JavaScript, pronto para GitHub Pages. Não exige instalação, compilação ou pagamento de serviço de formulário.

## Publicar passo a passo

1. Extraia o ZIP no computador.
2. Entre em https://github.com e crie um repositório público chamado `isaias-cabreira` (ou utilize o repositório do seu site).
3. Clique em **Add file > Upload files**. No repositório novo, pode aparecer **uploading an existing file**.
4. Arraste o CONTEÚDO da pasta extraída: `index.html`, `privacidade.html`, a pasta `assets` e os demais arquivos. Não envie somente o ZIP e não coloque o site dentro de uma pasta extra no repositório.
5. Clique em **Commit changes**. O arquivo `index.html` deve aparecer diretamente na raiz do repositório, ao lado da pasta `assets`.
6. Abra **Settings > Pages**.
7. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
8. Em **Branch**, escolha **main** e **/(root)**. Clique em **Save**.
9. Aguarde a publicação. O link aparece em **Settings > Pages**. O formato usual é `https://SEU-USUARIO.github.io/isaias-cabreira/`.
10. Abra o link e confira o site no celular e no computador. Se ainda aparecer a versão antiga, aguarde a execução na aba **Actions** e recarregue com Ctrl + F5.

Referência: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
